KI-Chat

Fragen zu Trading, Anlegen, deinem Portfolio und Ideen für die App. Antwortet Claude über deinen eigenen Zugang.

Einmal einrichten

Der Chat nutzt die Claude API von Anthropic mit deinem eigenen API-Schlüssel. Abgerechnet wird pro Nutzung direkt bei Anthropic; eine typische Frage mit dem günstigen Modell kostet deutlich unter einem Cent. Den Schlüssel bekommst du unter console.anthropic.com (Konto anlegen, Guthaben aufladen, „API Keys“). Er bleibt verschlüsselt auf diesem Gerät.

Mitgeschickt werden Name, ISIN, Anteil in % und Gewinn/Verlust in % je Position, aber keine Stückzahlen und keine Euro-Beträge. Ohne Haken weiß der Chat nichts über dein Depot.

Antworten können falsch sein und sind keine Anlageberatung. Aktuelle Kurse und Nachrichten kennt der Chat nur aus den Ratgeber-Daten der App.
